Epson RR-70W Batch Scanner

Home GitHub

Feed sheet after sheet without stopping. The scanner stays ready and takes the next page as soon as you hand it one, saving each as you go, auto-cropped to size.

Choose how you want them before you start: separate images, one file per page, or the whole stack as a single document.

Cropped To The Paper

Receipts and loose pages come out trimmed to their own edges, whatever size they happen to be, so you are not left straightening a hundred crooked images afterwards.

Getting it

Epson RR-70W batch scanner is free software. The source is on GitHub, and the repository is the whole distribution — there is no installer, no store listing and no account. 

git clone https://github.com/oisinmcgrath/epson-rr70w-autofeed.git
