4. System permissions you are granting

Installing Cadence for full functionality involves granting permissions that you should understand before you proceed. In summary — with the detail in the Privacy policy:

  • Keyboard access. Detecting a key being held requires reading the keyboard input device, which on Linux means access to all key events, not one key. The Software matches only its trigger key and discards the rest, but the operating system permission itself is broad. You are choosing to grant it.
  • Microphone access. Capture runs only between pressing and releasing the trigger key.
  • Virtual input (typing). The Software creates a virtual keyboard in order to type into other applications.

You are responsible for deciding whether these permissions are appropriate on your machine, particularly on a shared, managed, or employer-owned system where local policy may prohibit them. Check before installing if you are not the sole owner of the machine.

5. Accuracy of transcription

Speech recognition is imperfect. Cadence will sometimes mishear words, mispunctuate, drop audio, or insert text you did not say, and it types directly into whatever window has focus. Do not rely on it for anything where a transcription error would be costly without reviewing the output first — including but not limited to medical, legal, financial, safety-critical, or contractual text.

Because it types into the focused window, text can also land somewhere you did not intend if focus changes mid-dictation. Checking what was typed is your responsibility.
